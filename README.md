# 🛒 E-commerce Database Design Project

## 📌 Project Overview

This project demonstrates the design and implementation of an E-commerce Database using MySQL. It includes database creation, table design, sample data insertion, and SQL queries for business analysis.

This project was completed as part of my SQL learning journey to strengthen my database design and query writing skills.

---

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

---

## 📂 Project Files

- `create_database.sql` – Creates the database.
- `create_tables.sql` – Creates all required tables.
- `insert_data.sql` – Inserts sample data into the database.
- `analysis.sql` – Contains SQL queries for business analysis.

---

## 🗄️ Database Tables

The database contains the following tables:

- Customers
- Products
- Orders
- Order_Items
- Payments

---

## ✨ Features

- Database creation
- Table creation with Primary Keys and Foreign Keys
- Sample data insertion
- Business analysis using SQL queries
- Data relationships using JOIN operations

---

## 📊 Analysis Performed

The project includes SQL queries to analyze:

- Total Revenue
- Revenue by Product
- Top Customers by Spending
- Best Selling Products
- Cancelled Orders Count

---

## ▶️ How to Run

1. Execute `create_database.sql`
2. Execute `create_tables.sql`
3. Execute `insert_data.sql`
4. Execute `analysis.sql`
